# All Music

一款音乐播放器（Flutter）。

---

## 🚀 快速开始

```bash
flutter pub get
flutter run          # 连接设备或模拟器
```

### 测试

```bash
flutter test
flutter analyze
```

---

## 📱 平台支持

| 平台 | 支持 |
| ---- | ---- |
| Android | ✅  |
| iOS | 待测试 |
| Windows / macOS / Linux | ✅ 基础可用 |
| Web | ✅ 基础可用 |

本项目仅用于个人学习与技术交流。请尊重音乐版权，支持正版，勿将本项目用于商业用途或任何侵犯版权的场景。本项目与任何音乐平台均无关联，不提供、不存储任何音乐文件。
