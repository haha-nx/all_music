## SQLite 迁移幂等性修复 — duplicate column name: source_type

- **症状**: `SqfliteDatabaseException(duplicate column name: source_type (code 1 SQLITE_ERROR))` — `onUpgrade` 尝试 `ALTER TABLE music_sources ADD COLUMN source_type` 但列已存在
- **根因**: 开发期间数据库版本跟踪不一致（v1→v2 迁移已执行添加列，但版本号可能因 crash 未持久化），导致 `onUpgrade` 重复执行
- **修复**: `database_helper.dart` 新增 `_columnExists()` 方法，通过 `PRAGMA table_info(table)` 检查列是否存在；`_onUpgrade` 中在 `ALTER TABLE ADD COLUMN` 前先检查，使迁移幂等
- `flutter analyze` + `flutter build apk --debug` 均通过

## JS 源脚本搜索失败修复 — String.prototype 误判 + API 搜索回退

- **症状**: 导入 `https://ghproxy.net/raw.githubusercontent.com/pdone/lx-music-source/main/lx/latest.js` 后什么都搜不到
- **根因**: 该 LX Music 源脚本中 `MUSIC_SOURCE` 是一个**字符串**（平台标识如 "kuwo"），不是 Object。
  - 原检测 `typeof MUSIC_SOURCE !== 'undefined' && MUSIC_SOURCE.search` 被 `String.prototype.search`（JS 原生）误判为真 → 调用了字符串的 search 方法而不是歌曲搜索
  - `MUSIC_SOURCE.handleGetMusicUrl` / `MUSIC_SOURCE.getMusicUrl` 同理全部误判 — 从未真正调用脚本的函数
- **脚本真实结构**: 顶层函数 `handleGetMusicUrl()`, `handleGetMusicLyric()` + 全局变量 `API_URL`, `API_KEY`, `MUSIC_SOURCE` (string)。搜索功能不在脚本内，需通过 `API_URL` 调用后端 API 服务器。
- **修复** (`source_engine.dart` 重写):
  1. **对象模式检测**: `typeof MUSIC_SOURCE === 'object' && MUSIC_SOURCE !== null` → 精准排除字符串误判
  2. **全局模式检测**: 检查顶层 `handleGetMusicUrl` / `getMusicUrl` 等函数
  3. **API 服务器搜索回退**: 脚本无搜索函数时，提取 `API_URL`/`MUSIC_SOURCE`，通过 `httpFetch` 调用 API 服务器的搜索端点
  4. **多端点兼容**: 依次尝试 POST `/song/search`、GET `/song/search?keyword=...`、POST `/search` 三种格式
- search / getMusicUrl / getLyric 三方法均已同时支持对象模式和全局模式

## JS 搜索第四次修复 — 引擎初始化时序 bug

- **症状**: 导入音源时诊断 dump 正常，但搜索时无任何 `[API]` 输出（搜索根本没到 API 调用）
- **根因**: `_importScript()` 验证后立即 `engine.dispose()` 释放了引擎。搜索时 `getEngine(source.id)` 创建新引擎但从未调用 `init()`，导致 `_loaded=false` → `search()` 直接 `return []`
- **修复**:
  1. `_importScript`: 验证后用正式 source 重建引擎 → `init()` → 缓存到 `_engines[newSource.id]`
  2. `SourceNotifier.getEngine` → 改为 `Future<SourceEngine?>` async，内部确保 `init()` 后才返回
  3. `SourceApi` → 构造函数改为 `SourceApi._()` 私有 + `static Future<SourceApi> create()` async factory
  4. `search_provider.dart` + `player_provider.dart` 全部改为 `await SourceApi.create()`
